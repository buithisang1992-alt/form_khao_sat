Cấu Hình Google AppSheet API

Nhập thông tin kết nối từ AppSheet của bạn (Manage > Integrations > External API).

Mã định danh AppSheet của bạn.
Tên bảng dữ liệu trong AppSheet (khớp chính xác tên bảng hoặc tên Sheet).
Khóa API từ mục Manage > Integrations > External API.
Trình duyệt có thể chặn CORS khi gọi thẳng api.appsheet.com từ localhost/web. Bạn có thể dùng Webhook proxy hoặc App Script trung gian để vượt CORS mượt mà 100%.
